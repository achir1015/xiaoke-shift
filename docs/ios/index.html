⬇️ 安裝到這台 iPad／iPhone
  1. 請用 Safari 開這個網頁，按上面的按鈕，再按「安裝」。
  2. 回到主畫面等圖示下載完成。
  3. 第一次開啟若說要「開發者模式」：設定 → 隱私權與安全性 → 開發者模式 打開（會重新開機）。
  4. 只有登記過的裝置才能安裝；新的裝置請先跟開發者登記。
  5. 更新新版：再開這頁按一次安裝即可，班表資料會保留（建議先「⋯ → 備份班表」）。
