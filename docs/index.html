小柯班表助手

輪班班表＋農民曆＋小柯機器人

功能

  • 月曆排班：點一下排班，按住滑過一段日期一次設定；五份班表＋好友班表。
  • 農民曆：農曆、節氣、干支、宜忌、沖煞；台灣國定假日。
  • 班表樣式（循環班）、統計（工時、加班、借休、津貼、薪資）、發薪日。
  • 備註記錄：文字、心情、連結、照片、地圖。
  • 班別鬧鐘、行事曆同步（Google 行事曆）、桌面小工具。
  • 匯入病房助理工作站月班表（需單位管理者密碼）。
  • 小柯機器人連線：同一個 Wi-Fi 的小柯可以唸出你的班表。
  • iPad：左邊大月曆、右邊當天說明。

常見問題

換手機怎麼搬資料？ 舊手機「⋯ → 備份班表」存成 ZIP（可存到雲端硬碟），新手機「⋯ → 還原班表」。Android 與 iPhone／iPad 的備份可以互通。

鬧鐘不會響？ iOS 26 以上用系統鬧鐘；較舊的 iOS 用通知提醒，請允許通知。

匯入工作站班表要密碼？ 請向你所屬單位的管理者索取單位密碼。
